# 纽约海外学习指南

准备去纽约海外学习时，可以把这页当作整理问题和待办事项的起点。内容参考了学长学姐编写的[纽约生活指南](https://docs.google.com/document/d/1QEyxsBmimlLOzXvHRhJjy3yTRTMBi02mw1tIyirGSv4/edit?tab=t.0#heading=h.5lsgujjr7p58)和[纽约海外学习速查表](https://docs.google.com/document/d/1ry81Joo9VdIObJtmkDC-rBV7Skdn310yLkSoYXzjrRM/edit?usp=sharing)，两份原文都保留在页面下方。

::: warning 先核对当期信息
生活指南说明，涉及日期的信息来自 **2023–2024 学年**；速查表列有具体日程，但未注明适用学年。两份文档中的日期、费用、入境要求、宿舍和交通安排都不能直接视为当前规定。请以学校当期邮件、项目说明及相关官方机构的信息为准。
:::

## 先看申请与选课

- **住宿：**速查表将住宿申请、特殊住宿需求、取消申请和入住安排列为不同节点。先核对自己适用的申请入口及当期截止时间，再确认是否需要提交额外材料。
- **签证：**速查表收集了签证表格和面签预约的常见问题。填写或预约遇到问题时，可用它梳理问题，再向学校相关部门或官方渠道核实处理方式。
- **选课：**速查表汇集了课程评价、选课指南和课程要求对照资源。可把它们当作参考，最终以当期课程安排和学位要求为准。
- **通勤：**速查表整理了纽约校车线路与实时地图。出行前查看学校的实时线路信息，不要沿用旧时刻表。

## 出发前

- 核对护照、签证和学校要求的入境材料；按照当前通知确认哪些文件需要打印、签名或随身携带。
- 查收海外学习项目的行前说明，确认课程、住宿、保险和抵达流程。
- 参考原文中的[行李物品清单](https://docs.google.com/spreadsheets/d/182G_WtX7zr5LgAYVCOBdcrGfzHr7121p/edit?usp=drive_link&ouid=115005348850162066336&rtpof=true&sd=true)列自己的清单；药品与入境限制应另查现行规定。
- 规划从机场到住处的路线。行李较多或抵达时间较晚时，提前比较接机、出租车和公共交通的方案。
- 考虑刚落地时的支付和通讯方式，并保存重要文件的备份及紧急联系方式。

## 抵达后

- 按学校当期指引完成抵达登记、联系方式更新，以及适用于自己的出入境记录核对。
- 确认宿舍入住、校园卡、课程地点和通勤路线；交通线路及班次以实时信息为准。
- 根据实际需要办理本地电话与银行服务，先比较套餐、费用和转号条件。
- 熟悉住处附近的超市、药店、交通站点和校内支持渠道。
