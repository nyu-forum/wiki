# 认识 Forum

[NYU Forum](https://nyuforum.com/) 是同学交流的平台。你可以阅读帖子、文章与动态，也可以查看课程信息和同学提交的课程评价。

## 从哪里开始

| 入口 | 适合做什么 |
| --- | --- |
| 首页 | 浏览帖子、文章和动态，了解最近的校园讨论。 |
| 课程 | 按课程查找信息，结合课程评价了解同学的学习体验。 |
| 评价 | 阅读同学对课程的反馈；有亲身体验时也可以分享。 |
| 设置 | 管理自己的个人资料和显示偏好。 |

## 参与讨论

登录后可以发布内容、参与互动并查看通知。讨论课程时，尽量说明课程名称、任课教师和修读学期；分享经验时，注明信息所对应的时间。这样后来的同学更容易判断内容是否仍然适用。

Forum 上的帖子代表个人经验。选课要求、学术规定及项目安排，请以学校发布的信息为准。
