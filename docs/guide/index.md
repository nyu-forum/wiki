# Wiki 导览

NYU Forum Wiki 帮助同学了解 Forum、规划海外学习和寻找科研机会，也为新生提供入学起点。你可以按当前需要直接进入专题。

## 按主题阅读

- **刚入学：**阅读[新生入门](./getting-started)。
- **想参与同学讨论：**阅读[认识 Forum](./forum)，再进入 [Forum](https://nyuforum.com/)。
- **准备去纽约海外学习：**阅读[纽约海外学习指南](/study-away/new-york)，并查看页面链接的学长学姐原文。
- **想尝试科研：**阅读[寻找科研机会](/research/getting-started)。

## 使用这些信息

同学经验适合帮助你列问题、做准备。涉及申请资格、时间、签证、课程和住宿安排时，请再核对学校发给你的最新通知。
