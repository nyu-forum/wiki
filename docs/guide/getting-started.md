# 新生入门

> **内容标注：本页由 AI 生成。** 它把学校公开信息整理成行动清单，尚不能替代学校通知或人工答疑。请按你入学当年的邮件、页面和个人情况核对。

刚入学时先完成有截止时间的事项，再熟悉选课和校园生活。下面按“入学前—到校时—开学后”整理，你可以逐项勾选。

## 入学前：先做这五件事

- [ ] **启用并定期查看学校邮箱。** 学校会通过邮箱发送任务和截止时间。把需要提交的表格、住宿安排和迎新通知记到自己的日历里。先看学校的[入学前准备页面](https://shanghai.nyu.edu/campuslife/you-arrive)。
- [ ] **核对个人适用的入学要求。** 按邮件检查身份材料、健康与住宿手续。来自不同地区的学生办理流程可能不同；不要只凭他人的清单判断自己已完成。
- [ ] **完成线上迎新与学业指导任务。** 学校的[新生学业规划页面](https://shanghai.nyu.edu/content/first-year-planning)列出线上指导模块和课程规划入口。完成后保留确认信息，遇到系统问题及时联系负责部门。
- [ ] **准备第一版课程计划。** 在学校公布的课程信息中找出想修的课，记下先修要求、备选课程和想问学业导师的问题。选课流程以当期通知为准。
- [ ] **规划到校路线和入住。** 从学校的[新生页面](https://shanghai.nyu.edu/campuslife/first-year-students)进入当年的常见问题，并结合住宿通知确认入住时间、地点、所需材料和交通方式。

## 到校与迎新：把入口跑通

1. **参加学校安排的迎新活动。** 通过[新生迎新页面](https://shanghai.nyu.edu/campuslife/first-year-student-orientation)核对具体日程、地点和参与要求。
2. **测试常用入口。** 确认学校邮箱、课程系统、线上课程平台和校园卡能正常使用；遇到登录或权限问题，保存错误提示并联系对应支持团队。
3. **找到负责的人。** 对课程和培养要求有疑问，先找[学业指导办公室](https://shanghai.nyu.edu/advising)或分配给你的导师；对报到、住宿和迎新有疑问，查看学校通知中的联系渠道。
4. **认识校园与同学。** 记下教室、宿舍、食堂和常用服务地点；参加感兴趣的活动，也可以请迎新志愿者或学长学姐分享经验。

## 开学后：建立自己的信息习惯

- **每周检查一次课程安排和待办事项。** 对照教学平台、学校邮件与个人日历，避免错过作业、加退课和活动申请。
- **遇到选课疑问先核对官方要求。** 学校的[选课与学业指导说明](https://shanghai.nyu.edu/academics/bulletin/enrollment/registration-advisement-and-counseling)介绍了导师与选课系统的作用；同学评价可以帮助了解体验，不能代替学位要求。
- **用 Forum 补充同学视角。** 在 [Forum](https://nyuforum.com/) 搜索课程和校园生活讨论。发帖提问时写明课程、学期和具体问题，并留意旧帖的发布时间。
- **为以后做准备。** 对[海外学习](/study-away/new-york)或[科研机会](/research/getting-started)感兴趣，可以先收藏专题，不必在第一周就决定所有方向。

## 不知道该问谁时

先把问题写成一句话，并附上你已查过的通知或页面。涉及正式流程时，联系学校通知中的负责部门；课程规划可从[学业指导办公室](https://shanghai.nyu.edu/advising)开始。关于迎新，学校的[新生页面](https://shanghai.nyu.edu/campuslife/first-year-students)提供当期入口和联系方式。
