# 寻找科研机会

> **内容标注：本页由 AI 生成。** 这是一份行动指南，不代表学校项目说明或导师承诺。项目开放情况、资格、申请材料和截止时间请以官方页面为准。

科研不只发生在实验室。人文、社科、商科、艺术、计算等领域也有研究或创作项目。你可以先确定一个具体问题，再找合适的导师和机会。[学校本科生科研页面](https://shanghai.nyu.edu/page/research-and-conferences)介绍了科研基金、成果展示等入口。

## 第一步：把兴趣缩小成可讨论的问题

1. 从课程、阅读或生活观察中列出 **2—3 个主题**。例如，与其写“我对人工智能感兴趣”，不如写“我想比较两种方法在中文文本分类中的表现”。
2. 每个主题写下一个问题、你已掌握的技能，以及你还需要学习的工具或方法。
3. 找一篇相关论文、作品或项目介绍，记下它研究什么、用了什么方法、你看不懂什么。第一次接触不需要全部读懂。

## 第二步：找人和项目

| 路径 | 怎么做 |
| --- | --- |
| 导师方向 | 在学校的[教师目录](https://shanghai.nyu.edu/academics/faculty-directory)按学科找教师，阅读个人主页和近期项目，筛出与你的问题相关的 3—5 位。 |
| 正式项目 | 定期查看[学生科研机会汇总](https://research.shanghai.nyu.edu/cn/research-opportunities/student-research-opportunities)，记录项目适用对象、材料、截止时间和申请入口。 |
| 暑期研究基金 | [本科生暑期研究基金](https://shanghai.nyu.edu/content/deans-undergraduate-research-fund-durf)支持上海纽约大学本科生开展不同领域的研究；申请通常需要可执行的计划和导师支持，具体要求看当期页面。 |
| 课程与同学 | 向相关课程教师询问可阅读的材料或可能参与的方向；在 Forum 参考学长学姐经验时，核对项目是否仍开放。 |

不要把面向毕业生或全职雇员的岗位当成本科生项目。看到机会后，先读完整申请条件，再决定是否投入准备时间。

## 第三步：准备一份简短的联系材料

给导师联系前，准备以下内容：

- **一页简历：**列出相关课程、项目、技能和可供查看的作品链接；没有科研经历也可以写课程项目。
- **兴趣说明：**用两三句话说清你想研究的问题，以及为什么与对方的工作相关。
- **时间安排：**想好你每周可投入的时间、预计开始时间，以及是否希望参与现有项目或提出自己的想法。
- **具体问题：**例如“是否建议我先读某篇文章”或“本学期是否有本科生可参与的工作”。

下面是可按收件人语言调整的邮件结构。发送前请核对称呼、研究方向和附件，不要批量发送完全相同的邮件。

> **主题：**咨询关于〔研究主题〕的本科生参与机会<br>
> **称呼：**〔老师称呼〕您好，<br>
> 我是〔年级／专业方向〕学生，在〔课程或项目〕中接触了〔具体问题〕。我阅读了您关于〔具体研究〕的介绍，对〔一个明确的交点〕很感兴趣。<br>
> 我目前会〔相关技能〕，希望进一步学习〔方法〕。如果您有适合本科生参与的项目，或愿意推荐入门阅读，我很希望有机会进一步交流。附件是我的简历。<br>
> 感谢您的时间。〔姓名〕

## 第四步：交流与申请

- 交流前准备一段一分钟的自我介绍，以及 **2—3 个具体问题**：研究目标是什么、入门任务是什么、需要哪些技能和时间。
- 如项目要求申请书，先写研究问题、背景、方法、预期成果和时间安排，再请导师给反馈。以[项目当期说明](https://shanghai.nyu.edu/content/deans-undergraduate-research-fund-durf)规定的格式和材料为准。
- 如果暂时没有名额，可请对方推荐入门阅读、课程或未来申请时间。把交流收获记下来，继续联系更匹配的方向。
- 如果项目涉及访谈、问卷、个人数据或实验室操作，开始前先向导师确认伦理、安全和权限要求。

## 一周内可以完成的小目标

- **第 1—2 天：**选两个感兴趣的问题，各找一份入门材料。
- **第 3—4 天：**在教师目录和项目汇总中列出 3—5 个匹配对象，记录为什么匹配。
- **第 5 天：**整理一页简历和一段兴趣说明。
- **第 6—7 天：**请同学或导师帮你看一遍邮件，然后联系最匹配的一位，或按正式项目入口申请。

这份时间表只是帮助启动的建议；按自己的课程负担调整即可。科研方向通常需要反复探索，不必把第一次联系当成最终决定。
